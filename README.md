# Website – Portfolio

This repository contains the source code for the personal portfolio of **Jan Ole Petersen**.  
It showcases finished **game development** and **web development** projects; work that is still in development is not displayed in the live site.

The app is built with **Vue 3** and **Vite**, with basic routing and internationalization (German/English) for the portfolio content.

## Features

- **Games section**: Shows released game projects with videos, images, and links (e.g. itch.io).
- **Websites section**: Highlights web projects such as research and university work.
- **Multilingual**: Content available in German and English via a simple i18n setup.
- **Accessibility focus**: Semantic structure, modals, and color system designed with accessibility in mind.
